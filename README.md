# Bulk Lorebook Tools

**Массовые операции с записями в лорбуках (World Info) для SillyTavern.**

Расширение добавляет в редактор World Info панель, в которой можно отметить
чекбоксами сразу десятки записей и за один раз **скопировать**, **перенести** их
в другой лорбук или **удалить** — вместо того чтобы щёлкать по каждой записи
отдельно.

## Зачем это нужно

В стандартном редакторе World Info у каждой записи есть свои кнопки —
«перенести/скопировать» (⇄), «дублировать» (📋) и «удалить» (🗑). Когда записей
сотни, а перенести нужно пол-лорбука, это превращается в часы однообразных
кликов.

**Bulk Lorebook Tools** даёт один список с чекбоксами и четыре действия над
всем выделением сразу.

## Возможности

| Возможность | Что делает |
|---|---|
| ☑ Массовый выбор | Чекбоксы для всех записей лорбука + поиск по названию, кнопки **Все** / **Ничего** / **Инверсия** и счётчик выбранных |
| 📋 Скопировать в целевой | Дублирует выбранные записи в другой лорбук; исходный лорбук не меняется |
| ⇄ Перенести в целевой | Копирует записи в другой лорбук и удаляет их из исходного (с подтверждением) |
| 🗑 Удалить выбранные | Удаляет сразу все отмеченные записи из текущего лорбука (с подтверждением) |
| ➕ Новый лорбук | Создать целевой лорбук, не выходя из панели |
| 🧩 Пропуск дубликатов | Не копировать записи, у которых такое же название уже есть в целевом лорбуке |
| 🔄 Автообновление | Список сам обновляется при изменении лорбука и следует за книгой, открытой в редакторе |
| 🌐 RU / EN | Интерфейс автоматически переводится, если язык SillyTavern — русский |

## Установка

### Способ 1. Через интерфейс SillyTavern (рекомендуется)

1. Открой SillyTavern.
2. Нажми иконку **«палочки»** (Extensions) в верхнем ряду кнопок.
3. В блоке **Install Extension** вставь ссылку на этот репозиторий:

   ```
   https://github.com/ТВОЙ_НИК/BulkLorebookTools
   ```

4. Нажми **Install for me** и подтверди установку.
5. Перезагрузи страницу (Ctrl+F5).

### Способ 2. Вручную

Скопируй папку `bulk-lorebook-tools` (внутри обязателен `manifest.json`) в:

```
<SillyTavern>/public/scripts/extensions/third-party/
```

и перезагрузи страницу.

### Обновление

Через интерфейс — кнопка 🔄 рядом с расширением в панели **Extensions**.
Вручную:

```bash
cd "<SillyTavern>/public/scripts/extensions/third-party/bulk-lorebook-tools"
git pull
```

## Как пользоваться

### 1. Открой панель

Открой **World Info** (иконка 🌐) и найди в строке инструментов кнопку со
«слоями» — она стоит сразу справа от кнопки **+** (New Entry).
Нажми её: под строкой кнопок, над списком записей, развернётся панель.
Повторное нажатие или ✖ в её шапке закрывает панель.

### 2. Выбери рабочий лорбук

Поле **«Рабочий лорбук»** — это книга, из которой берутся записи.
По умолчанию подставляется лорбук, открытый в редакторе; кнопка **⟳** рядом
с полем сбрасывает выбор на тот, что открыт в редакторе (удобно, если ты
успела полистать другие книги).

### 3. Отметь записи

- Клик по строке или по чекбоксу — включить/выключить запись.
- **Поиск записей…** — фильтр по названию (Memo/Title).
- **Все** — отметить все записи, попадающие под фильтр.
- **Ничего** — снять отметку у отфильтрованных.
- **Инверсия** — перевернуть выбор у отфильтрованных.
- Счётчик «Выбрано: N» показывает, сколько отмечено.

Кнопки **Все / Ничего / Инверсия** работают **с учётом фильтра поиска** —
это удобно: набери `Jackson`, нажми **Все** и работай только с этой семьёй.

Записи, выключенные в лорбуке (`disable`), показываются зачёркнутым текстом.
Число справа (`#12`) — это UID записи в файле лорбука; он помогает не путать
одноимённые записи.

### 4. Скопируй или перенеси в другой лорбук

1. Выбери **«Целевой лорбук»** — книгу, в которую попадут записи.
   Нужной нет? Нажми **Новый**, введи название — пустой лорбук создастся сразу
   и подставится как целевой.
2. Оставь включённой галку **«Пропускать дубликаты по названию»**, если не
   хочешь копировать записи, которые уже есть в целевой книге с тем же
   названием. Сними галку, если нужно продублировать всё как есть.
3. Нажми одну из кнопок:
   - **Скопировать в целевой** — записи добавятся в целевую книгу, исходная
     не изменится;
   - **Перенести в целевой** — записи добавятся в целевую и удалятся из
     исходной (перед этим SillyTavern спросит подтверждение).

Записи добавляются **в конец** целевого лорбука, а порядок между ними
сохраняется. Переносятся все поля: ключевые слова, контент, позиция, глубина,
order, вероятность, триггеры, тайминги, связи с группами и т.д. — ровно так же,
как при обычном дублировании средствами SillyTavern.

### 5. Удали сразу несколько

1. В поле **«Рабочий лорбук»** выбери книгу, из которой удалять
   (можно и другую — не ту, что открыта в редакторе).
2. Отметь записи и нажми **Удалить выбранные**.
3. Подтверди во всплывающем окне.

Удаление необратимо. Если книга важная — сделай бэкап её файла заранее
(`<SillyTavern>/data/<твой-логин>/worlds/<Имя лорбука>.json`).

### Подсказки

- Отметки не сбрасываются при автообновлении списка — можно спокойно
  редактировать лорбук в обычном редакторе параллельно.
- Если список лорбуков изменился (создала/удалила книгу в другом месте) —
  нажми **⟳**, список книг перечитается.
- «Скопировать в целевой» + «Удалить выбранные» из исходного = «Перенести
  в целевой», но в два шага. Иногда так удобнее.

## Частые вопросы

**Записи правда сохраняются на диск сразу?**
Да. Копирование, перенос и удаление вызывают немедленное сохранение файла
лорбука (`saveWorldInfo(name, data, true)`), без ожидания «отложенного»
сохранения редактора. Файлы лежат в `data/<логин>/worlds/*.json`.

**Куда именно попадают записи в целевом лорбуке?**
В конец списка, с новыми UID и последовательными `displayIndex`. Если в
целевом лорбуке выбрана сортировка «Custom», записи окажутся внизу.

**Переносятся ли UID?**
Нет. UID уникален внутри файла, поэтому скопированным записям выдаются новые
свободные UID. Всё остальное содержимое переносится как есть.

**Что считается «дубликатом» при включённой галке пропуска?**
Совпадение названия (Memo/Title) без учёта регистра и пробелов по краям.
Записи без названия дубликатами не считаются и копируются всегда.

**Есть ли ограничение по количеству записей?**
Панель рисует не больше 1000 строк за раз — для остального используй поиск.
Сами операции работают с любым количеством выбранных записей.

**Можно ли отменить операцию?**
Только вручную (перенести обратно / восстановить из бэкапа). Поэтому перенос
и удаление спрашивают подтверждение. Перед массовыми операциями полезно
скопировать папку `worlds` целиком.

**Работает ли это с лорбуками персонажей и чатов?**
Панель работает с обычными лорбуками из списка World Info. Встроенные
(embedded) лорбуки персонажей в список редактора не входят.

**Почему интерфейс на английском?**
Язык берётся из настроек SillyTavern: `ru-ru` → русский, иначе — английский.

## Совместимость

- SillyTavern **1.12+** (проверено на 1.19.1, актуальная ветка `release`).
- Зависимостей нет: используется только публичный API
  `SillyTavern.getContext()`.
- Совместимо с другими расширениями: своя панель со своим префиксом `blt-*`
  в DOM и CSS, ничего в ядре не патчится.

## Как это устроено

| Файл | Назначение |
|---|---|
| `manifest.json` | манифест расширения SillyTavern |
| `index.js` | вся логика: панель, список, операции |
| `style.css` | оформление, использует CSS-переменные темы (`--SmartTheme*`) |
| `CHANGELOG.md` | история изменений |
| `LICENSE` | AGPL-3.0 |

Ключевые моменты реализации:

- `loadWorldInfo()` отдаёт **копию** данных из кэша ядра, поэтому код идёт по
  пути «прочитать → изменить → `saveWorldInfo(name, data, true)`» — тем же
  самым, которым пользуется штатное дублирование и перенос записей в ядре
  SillyTavern.
- После сохранения вызывается `reloadEditor()`, если изменённая книга открыта
  в редакторе, — список записей не «расходится» с файлом.
- Слушается событие `WORLDINFO_UPDATED`, чтобы панель обновлялась сама.
- Поле `originalData` (исходный JSON импортированной книги) синхронизируется
  при удалении и переносе — как в ядре.

## Разработка

Репозиторий удобно держать прямо в папке расширения:

```
<SillyTavern>/public/scripts/extensions/third-party/bulk-lorebook-tools/
```

SillyTavern отдаёт эту папку как `global`-расширение, а `.gitignore` самого
SillyTavern игнорирует весь `third-party`, поэтому репозитории не мешают
друг другу и не попадают в апстрим.

Сборка не нужна — это обычный ES-модуль. После правок просто обнови страницу
(Ctrl+F5). Полезные точки для отладки: консоль браузера (F12), сообщения с
префиксом `[BulkLorebookTools]`.

Pull requests и issues приветствуются. Если добавляешь возможность —
обнови `CHANGELOG.md` и подними `version` в `manifest.json`.

При желании добавь в `manifest.json` ссылку на репозиторий:

```json
"homePage": "https://github.com/ТВОЙ_НИК/BulkLorebookTools"
```

## English

**Bulk Lorebook Tools** — bulk operations for SillyTavern World Info (lorebooks).

### Features

- Checkbox list of every entry of a lorebook, plus search and
  **All / None / Invert** buttons and a selection counter.
- **Copy** the selected entries into another lorebook in one click.
- **Move** the selected entries into another lorebook (copy + delete from source).
- **Delete** many entries at once.
- Create the target lorebook on the fly (**New**).
- Optional duplicate skipping by entry title.
- Auto-refresh on lorebook changes; follows the book opened in the editor.
- UI is translated to Russian when SillyTavern's language is `ru-ru`.

### Installation

1. Open SillyTavern → **Extensions** (the wand icon).
2. Paste the repository URL into **Install Extension** and click **Install for me**.
3. Reload the page (Ctrl+F5).

Manual install: copy the `bulk-lorebook-tools` folder (with `manifest.json`
inside) into `<SillyTavern>/public/scripts/extensions/third-party/`.

### Usage

1. Open **World Info** and click the layers button next to **+** (New Entry).
2. Pick the **Working book** (defaults to the book opened in the editor).
3. Tick entries, or filter with the search box and press **All**.
4. Choose the **Target book** and press **Copy to target** or **Move to target**,
   or press **Delete selected** to remove them from the working book.

### Compatibility

SillyTavern 1.12+ (tested on 1.19.1). No dependencies — it uses the public
`SillyTavern.getContext()` API only.
